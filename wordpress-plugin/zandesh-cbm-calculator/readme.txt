100% Free interactive 3D shipping container loading planner, CBM volume calculator, and export freight proforma invoice generator. Fully compatible with Elementor, WPML, Polylang, and shortcodes.

== Description ==

**Zandesh CBM** is a professional, 100% free international freight and 3D container loading simulation plugin for WordPress, developed and supported by **Zandesh Logistics Group** (zandesh.com).

Whether you run an international trade firm, e-commerce store, freight forwarding agency, or customs clearance service, Zandesh CBM allows your website visitors to calculate package cubic meters (CBM), determine ocean and air chargeable weight, and visualize 3D container stuffing inside standard 20ft, 40ft, 40ft High Cube containers and 13.6m commercial trucks.

### 🌟 Key Features

* **100% Free & Unlimited**: No subscription, no API key required, zero limits.
* **Elementor Dedicated Widget**: Drag and drop the "Zandesh CBM" widget anywhere with live customization for colors, languages, and view modes.
* **WordPress Shortcode**: Simple `[zandesh_cbm]` shortcode for Gutenberg blocks, classic editor, or widgets.
* **Interactive 3D WebGL Simulator**: Powered by Three.js with full 360° orbital rotation, zoom, wireframe toggle, and step-by-step loading animation.
* **9 International Languages**: Persian (فارسی), English, Arabic (العربية), Chinese (中文), Russian (Русский), Spanish (Español), Turkish (Türkçe), German (Deutsch), and French (Français).
* **Automatic RTL / LTR Layout**: Flawless right-to-left directional handling for Persian and Arabic.
* **Multi-language Plugin Compatibility**: Seamlessly works with WPML, Polylang, and TranslatePress with automatic active language detection.
* **Commercial Proforma Invoice Generator**: Generate standard export freight proforma invoices with your own company name, logo, WhatsApp contact, and printable PDF format.
* **Standard Container & Truck Profiles**: ISO 20ft Standard (33.2 m³), 40ft Standard (67.7 m³), 40ft High Cube (76.4 m³), and European 13.6m Truck (90.0 m³).
* **Isolated Lightweight Architecture**: Scoped CSS prevents any styling conflicts with Astra, Hello Elementor, WoodMart, or other themes. Scripts load on-demand only when the widget is present.

== Installation ==

### From WordPress Admin Dashboard:
1. Go to **Plugins > Add New > Upload Plugin**.
2. Upload the `zandesh-cbm-calculator.zip` file.
3. Click **Install Now** and then **Activate Plugin**.
4. Navigate to **Zandesh CBM** in your WordPress admin menu to configure your branding color, company details, and logo.

### Displaying the Calculator:
* **Using Elementor**: Edit your page with Elementor, search for **Zandesh CBM & 3D Container** in the elements panel, and drag it into your layout.
* **Using Shortcode**: Insert `[zandesh_cbm]` into any Gutenberg block, page, or post.
